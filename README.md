# UESC Projects

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Open Source](https://img.shields.io/badge/Open%20Source-Yes-green.svg)](https://opensource.org/)

This repository contains abstracts, code, and study materials for various projects developed at UESC (Santa Cruz State University). Each project is designed to demonstrate different aspects of computer science, including cryptography, parallel processing, data warehousing, and more.

## Projects

- [AES Crypto](https://github.com/patricksferraz/uesc/tree/all/aes-crypto) - Implementation of AES encryption algorithms.
- [Bolzano Theorem](https://github.com/patricksferraz/uesc/tree/all/bolzano-theorem) - Implementation of the Bolzano theorem.
- [Cesar Crypto C](https://github.com/patricksferraz/uesc/tree/all/cesar-crypto-c) - Implementation of the Caesar cipher in C.
- [Cesar Crypto](https://github.com/patricksferraz/uesc/tree/all/cesar-crypto) - Implementation of the Caesar cipher.
- [Crosswords Game](https://github.com/patricksferraz/uesc/tree/all/crosswords-game) - A game developed in Programming Language III.
- [Data Warehouse](https://github.com/patricksferraz/uesc/tree/all/data-warehouse) - Data warehousing project.
- [Degas Health](https://github.com/patricksferraz/uesc/tree/all/degas-health) - Health-related project.
- [DES Crypto](https://github.com/patricksferraz/uesc/tree/all/des-crypto) - Implementation of DES encryption.
- [Distributed Hash Table](https://github.com/patricksferraz/uesc/tree/all/distributed-hash-table) - Implementation of a distributed hash table for file sharing.
- [Huffman Compress](https://github.com/patricksferraz/uesc/tree/all/huffman-compress) - Implementation of Huffman compression.
- [LZ77 Compress](https://github.com/patricksferraz/uesc/tree/all/lz77-compress) - Implementation of LZ77 compression.
- [Nim Game Site](https://github.com/patricksferraz/uesc/tree/all/nim-game-site) - A web-based Nim game.
- [Parallel Processing](https://github.com/patricksferraz/uesc/tree/all/parallel-processing) - Projects related to parallel processing.
- [Polyalphabetic Crypto](https://github.com/patricksferraz/uesc/tree/all/polyalphabetic-crypto) - Implementation of polyalphabetic encryption.
- [Pong Game](https://github.com/patricksferraz/uesc/tree/all/pong-game) - A simple Pong game using OpenGL.
- [RSA Crypto](https://github.com/patricksferraz/uesc/tree/all/rsa-crypto) - Implementation of RSA encryption.
- [Run Length Encode Compress](https://github.com/patricksferraz/uesc/tree/all/run-length-encode-compress) - Implementation of run-length encoding compression.
- [Scanner Portugol](https://github.com/patricksferraz/uesc/tree/all/scanner-portugol) - A scanner for the Portugol language.
- [Single Key Crypto](https://github.com/patricksferraz/uesc/tree/all/single-key-crypto) - Implementation of single-key encryption.
- [TCP Socket](https://github.com/patricksferraz/uesc/tree/all/tcp-socket) - Implementation of TCP socket communication.
- [UDP Socket](https://github.com/patricksferraz/uesc/tree/all/udp-socket) - Implementation of UDP socket communication.
